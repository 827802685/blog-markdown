# 贪吃蛇小游戏（Cloudflare Workers 版）

## 项目概述

这是一款专为多端适配设计的贪吃蛇小游戏，支持部署在 Cloudflare Workers 上，无需额外服务器即可通过互联网访问。游戏融合了经典贪吃蛇玩法与现代交互设计，同时适配手机端（触屏操作）和桌面端（键盘 / 鼠标操作），提供流畅的跨设备游戏体验。

## 核心功能

功能模块	具体说明
多端自适应布局	自动识别设备类型（手机 / 桌面），调整界面布局和控制方式，适配不同屏幕尺寸
多样化控制方式	手机端：触摸按钮 + 滑动控制；桌面端：键盘（WASD / 方向键）+ 屏幕按钮
完整游戏流程	包含「开始界面 → 游戏界面 → 结束提示 → 结算页面」四阶段，体验闭环
进阶游戏机制	吃食物得分、蛇身增长、随机生成障碍物、分数越高速度越快（难度递增）
成绩记录功能	本地存储（localStorage）历史最佳成绩，支持结算页展示本局与最佳成绩对比
加速功能	支持临时加速（手机端点击加速按钮 / 桌面端按空格键），提升游戏操作性

## 技术栈

技术 / 工具	用途说明
HTML5 Canvas	游戏画面渲染（蛇身、食物、障碍物的动态绘制）
Tailwind CSS	快速实现响应式布局与视觉样式，无需编写原生 CSS
JavaScript	游戏逻辑核心（控制、碰撞检测、分数计算、状态管理）
Cloudflare Workers	服务器端部署载体，接收请求并返回完整游戏页面，实现无服务器访问
Font Awesome	提供方向键、加速按钮等图标，优化视觉交互

## 部署指南（Cloudflare Workers）

### 前提条件

拥有 Cloudflare 账号（免费账号即可）
已完成 Cloudflare 账号实名认证（部分地区要求）

### 部署步骤

##### 登录 Cloudflare 控制台

访问 Cloudflare 官网，登录账号后进入「Workers 和 Pages」页面。

##### 创建 Worker

点击「创建应用」→ 选择「Worker」→ 点击「创建 Worker」。
自定义 Worker 名称（如 snake-game-demo），点击「部署」进入代码编辑器。

##### 替换 Worker 代码

删除编辑器中默认的示例代码，将本项目的 worker.js 完整代码粘贴进去。
点击编辑器顶部的「保存并部署」，等待部署完成（通常耗时 < 10 秒）。

##### 访问游戏

部署成功后，通过 Worker 提供的默认域名（如 snake-game-demo.xxx.workers.dev）访问游戏，也可绑定自定义域名（需提前在 Cloudflare 管理域名）。

## 使用说明

1. ##### 手机端操作（触屏设备）

  | 操作目标     | 操作方式                                                     |
  | ------------ | ------------------------------------------------------------ |
  | 控制蛇的方向 | 方式 1：点击屏幕下方「上 / 下 / 左 / 右」触摸按钮；方式 2：在「滑动区域」滑动手势 |
  | 临时加速     | 点击屏幕下方的「闪电图标」加速按钮（按住加速，松开恢复正常速度） |
  | 开始游戏     | 点击初始界面的「START」按钮                                  |
  | 重新开始     | 游戏结束后点击结算页面空白处，返回开始界面                   |

  
2. ##### 桌面端操作（电脑）

  | 操作目标     | 操作方式                                                     |
  | ------------ | ------------------------------------------------------------ |
  | 控制蛇的方向 | 方式 1：键盘「WASD」或「方向键」；方式 2：点击左侧屏幕方向按钮 |
  | 临时加速     | 按下键盘「空格键」（按住加速，松开恢复正常速度)              |
  | 开始游戏     | 点击「START」按钮或按键盘「Enter」键                         |
  | 重新开始     | 结算页面点击空白处，或按「Enter」键返回开始界面              |

  

  ## 游戏规则

  ##### 基础玩法：

  控制蛇头移动，吃掉黄色圆形「食物」可得分（+100 分 / 个），同时蛇身自动增长一节；

  ##### 结束条件：

  蛇头撞到屏幕边缘、撞到自身蛇身、撞到紫色「障碍物」，游戏立即结束；

  ##### 难度递增：

  每吃 10 个食物，随机生成 1 个障碍物；
  每累计 1000 分，游戏基础速度提升（最低速度限制为 50ms / 帧）；

  ##### 加速机制：

  加速状态下移动速度提升约 1 倍（正常速度 150ms / 帧 → 加速 70ms / 帧），适合快速躲避障碍物。

  ## 注意事项

  ##### 浏览器兼容性：

  支持主流现代浏览器（Chrome、Safari、Edge、Firefox），不支持 IE 等老旧浏览器；

  ##### 数据存储说明：

  历史最佳成绩存储在本地浏览器的 localStorage 中，清除浏览器缓存或更换设备后会重置；

  ##### 手机端体验优化：

  游戏已禁用页面缩放（<meta name="viewport" content="user-scalable=no">），避免误触缩放影响操作；

  ##### 性能说明：

  基于 Canvas 轻量级渲染，低配置设备（如老旧手机）也可流畅运行，无明显卡顿。

  ## 功能亮点

  1. 零服务器成本：基于 Cloudflare Workers 部署，免费额度满足个人使用（每日 10 万次请求）；
  2. 极致跨端体验：手机端优化触摸反馈（按钮按下动画），桌面端支持键盘快捷操作，兼顾效率与易用性；
  3. 视觉设计友好：采用渐变色彩 + 复古边框风格，游戏元素（蛇身 / 食物 / 障碍物）颜色区分清晰，辨识度高；
  4. 代码可扩展性：核心逻辑模块化（如 initGame()、generateFood()），便于后续添加新功能（如关卡模式、皮肤系统）。
